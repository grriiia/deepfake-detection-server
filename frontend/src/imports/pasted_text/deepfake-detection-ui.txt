Create a full web UI design system and multi-page dashboard for an AI forensic deepfake detection service.

Concept:
This platform detects deepfakes by extracting face regions with RetinaFace and classifying visual artifacts with an EfficientNet-B4 model using SBI weights. The UI should feel trustworthy, scientific, explainable, and suitable for an AI forensic computer vision service.

Design style:
- dark navy / slate background
- cyan and blue accent colors
- rounded cards with soft shadows
- modern SaaS + AI forensic dashboard aesthetic
- high readability, structured layout, premium typography
- clean data visualizations and explainable AI interface
- serious, reliable, and technically advanced feel

Pages to generate:
1. Landing page
2. Login / Signup page
3. Video upload / live capture page
4. Pre-analysis quality check page
5. Analysis progress page
6. Result page with explainable AI signal visualizations
7. Analysis history page
8. Admin dashboard page

Important UI elements:
- video upload and webcam capture
- detected face overlay and alignment guide
- frame confidence charts and artifact trend charts
- time delay comparison graph
- facial heatmap and saliency visualization
- confidence score, quality score, verdict badge
- history records and admin analytics

The design should look like a real product that could be presented as a graduation project in AI, computer vision, or healthcare-adjacent digital forensics.
